 Descripción

Esta práctica consiste en desplegar sobre Docker y Docker Compose la
infraestructura base de identidad de SecureCorp.

El sistema está formado por:

Infraestructura de red con Docker.

Una CA intermedia para la emisión de certificados.

Un servidor de directorio con OpenLDAP.

Un KDC con Kerberos.

Un cliente para realizar las pruebas de autenticación y acceso.

Un equipo de administración.

Un contenedor fw-perimeter que actúa como router entre la LAN y la
DMZ.

Esta infraestructura será la base de las siguientes prácticas del
módulo.
